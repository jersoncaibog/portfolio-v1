## Overview

The Smart Home Automation System with Hand Gesture Recognition is an **AI-powered IoT solution** designed to improve accessibility in smart homes. Unlike conventional systems that rely heavily on mobile apps or voice assistants, this project leverages **computer vision and machine learning** to recognize customizable hand gestures in real time, allowing users to control appliances, lighting, and security systems without physical interaction.

The system was developed as a **capstone project** for the Bachelor of Science in Information Technology at Eastern Samar State University. It emphasizes inclusivity, targeting individuals with mobility or speech impairments while also providing a touchless, futuristic experience for all users.

## Key Features

- **Gesture Recognition with AI**: Real-time detection of customizable hand gestures using computer vision and machine learning.
- **IoT Device Control**: Integration with ESP32/ESP32-CAM and relay modules to manage lighting, appliances, and security devices.
- **Customizable Commands**: Users can define gestures based on personal preference and comfort.
- **Web Dashboard**: A full-stack web interface for monitoring and manual control of devices, with live camera feed integration.
- **Offline Functionality**: Reliable performance in varying indoor conditions, even without internet connectivity.
- **Agile Development Approach**: Iterative design, testing, and refinement following the Agile model.

## Technologies Used

- **Frontend**: React.js, Tailwind CSS  
- **Backend**: Python (FastAPI), WebSocket  
- **AI/ML**: OpenCV, TensorFlow  
- **IoT Hardware**: ESP32, ESP32-CAM, Relay Modules, Contactors
- **Database**: PostgreSQL
- **Other Tools**: Postman, Arduino IDE, VS Code

## Evaluation & Results

The system was tested in three phases:  

- **Benchmark Test**: Rated 100% Excellent across all categories.  
- **Pilot Test (IT Experts)**: Achieved an overall rating of 4.83 (Excellent).  
- **Final Test (Homeowners)**: Achieved an overall rating of 4.88 (Excellent).  

The **System Usability Scale (SUS) score** was **92.83 (Grade A, Excellent)**, confirming the system’s high usability and acceptance.

## Conclusion

This project demonstrates the feasibility and effectiveness of **gesture-based smart home automation**. It enhances independence and accessibility for people with mobility or speech impairments while showcasing the integration of **AI, IoT, and computer vision** in practical applications.
